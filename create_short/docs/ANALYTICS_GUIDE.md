# 📊 アナリティクス機能 使い方ガイド

## 🎯 概要

このシステムは**動画の再生数を記録・分析し、AIが過去の成功パターンから学習して次の台本を最適化**する機能です。

## 🔄 学習サイクル

```
1. 動画生成 → 自動でDBに記録
2. 再生数を入力（手動）
3. システムが成功パターンを自動分析
4. 次回の台本生成時、AIが学習データを活用
5. 繰り返し → 精度向上
```

## 📝 基本的な使い方

### 1. 動画生成（自動記録）

通常通り動画を生成すると、自動的にデータベースに記録されます：
- タイトル
- 台本内容
- キーワード
- 生成日時

### 2. 再生数の入力

**方法A: Webアプリから**
1. ブラウザで `http://localhost:5000` を開く
2. 「📊 アナリティクス」セクションへスクロール
3. 動画一覧の「編集」ボタンをクリック
4. 再生数・いいね・コメント数を入力

**方法B: コマンドライン**
```python
from db_manager import update_video_metrics, get_video_by_path

# 動画のパスからID取得
video = get_video_by_path("data/videos/draft/psychology_shinrigaku_20251109.mp4")

# メトリクス更新
update_video_metrics(
    video_id=video['id'],
    views=15000,
    likes=800,
    comments=50,
    retention_rate=75.5  # オプション
)
```

### 3. インサイトの確認

**Webアプリで確認:**
- 「💡 AI インサイト」セクションに自動表示
- 各アカウントの成功パターンが表示されます

**例:**
```
✅ 疑問形で始まる動画の再生数が高い傾向
✅ 最高再生数の動画は9行構成
✅ 効果的なキーワード: psychology, personality, test
✅ 'フォロー'促進CTAが効果的
```

### 4. AI学習の確認

次回の台本生成時、自動的に学習データが活用されます：

```bash
./scripts/test_generation.sh
```

生成ログに `🎓 学習データを活用してプロンプト生成` と表示されれば成功です。

## 🔍 分析レポート

### 自動生成レポート

分析実行時に自動でJSONレポートが生成されます：

```
data/analytics/reports/analysis_心理テストラボ_20251109.json
```

### 手動で分析実行

```python

# レポート生成
report_file = save_analysis_report("心理テストラボ")

```

### レポート内容

- サンプル数
- 平均再生数
- 冒頭パターン分析
- 最適な長さ
- 効果的なキーワード
- CTAパターン分析
- 成功事例（上位3動画）
- 実用的なインサイト

## 📈 統計情報の確認

### Webアプリで確認

「📊 アナリティクス」セクションで以下が確認できます：
- 各アカウントの動画数
- 平均再生数

## 🤖 AI学習の仕組み

### 学習プロンプト生成

`learning_prompt.py` が以下を自動分析：

1. **冒頭パターン**: 疑問形 vs 宣言形 vs 感嘆形
2. **最適な長さ**: 最高再生数の動画の行数
3. **効果的なキーワード**: 頻出キーワードトップ5
4. **CTAスタイル**: フォロー促進 vs コメント促進
5. **成功事例**: 実際の台本を参考情報として提示

### プロンプト強化

生成されたプロンプトには以下が含まれます：

```
【過去の成功パターンを活用】
- 成功例の冒頭: 「あなたの隠れた性格を当てます」
- 最適な行数: 9行程度
- 効果的なキーワード: psychology, personality, test
- CTAは「フォロー」促進が効果的

【成功事例（再生数トップ）】
タイトル: 【心理テスト】あなたの性格は？
台本: ...
```

## 💡 活用のコツ

### 最低限のデータ量

- **推奨**: 各アカウント最低10動画
- **理想**: 各アカウント30動画以上

データが多いほど分析精度が向上します。

### 定期的な更新

週1回程度、再生数を更新すると良いでしょう：

1. YouTube/TikTokのアナリティクスを確認
2. Webアプリで再生数を入力
3. システムが自動で再分析
4. 次回の台本生成に反映

### A/Bテスト

異なるパターンを試して比較：
- 疑問形 vs 宣言形の冒頭
- フォローCTA vs コメントCTA
- 短い台本 vs 長い台本

結果を記録して、データ駆動で改善していきましょう。

## 🐛 トラブルシューティング

### インサイトが表示されない

**原因**: データ不足

**解決策**:
1. 動画を生成
2. 再生数を入力（最低5動画）
3. ページをリロード

### 学習が効いていない

**確認方法**:
```bash
python3 learning_prompt.py
```

データがあれば学習プロンプトが表示されます。

### データベースエラー

**リセット方法**:
```bash
rm data/database/videos.db
python3 db_manager.py
```
