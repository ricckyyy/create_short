## 🔄 実行フロー

### 1. トリガー
- **自動実行**: cron式で指定した時刻（デフォルト: 毎日6:00 AM JST）
- **手動実行**: GitHub UI から「Run workflow」ボタン

### 2. 環境セットアップ
```yaml
- Python 3.9
- 依存パッケージ（requirements.txt）
- 必要なディレクトリ構造
```

### 3. サービス確認
```
Ollama (http://127.0.0.1:11434)
  └── モデル: gemma2:9b (または環境変数で指定)

VOICEVOX (http://127.0.0.1:50021)
  └── Docker コンテナ
```

### 4. 動画生成処理
```
各アカウント（心理テストラボ、闇夜の語り部、映画紹介）に対して:
  1. 台本生成 (AI)
  2. 音声合成 (VOICEVOX)
  3. 動画素材取得 (Pexels/Pixabay)
  4. 動画編集 (MoviePy)
  5. メタデータ生成
```

### 5. 結果の保存
```
GitHub Artifacts (7日間保存)
  └── generated-videos-{run_number}.zip
        ├── data/videos/draft/*.mp4
        ├── data/upload/descriptions_*.txt
        └── data/logs/generation/*.log

ローカル (セルフホストランナーの場合)
  └── data/
        ├── videos/draft/
        ├── audio/
        ├── scripts/history/
        └── logs/generation/
```

## 📊 2つの実行モード比較

| 項目 | セルフホストランナー | GitHub-hosted ランナー |
|------|---------------------|----------------------|
| **サーバー** | 自前で用意 | GitHub提供 |
| **初期設定** | 必要 | 不要 |
| **実行時間** | 速い（15-30分） | 遅い（30-60分） |
| **安定性** | 高い | 中程度 |
| **コスト** | サーバー維持費 | 無料（制限あり） |
| **ストレージ** | 無制限 | Artifacts（7日間） |
| **推奨度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 🔧 カスタマイズポイント

### スケジュール変更
```yaml
schedule:
  - cron: '0 21 * * *'  # UTC時刻で指定
```

### タイムアウト調整
```yaml
timeout-minutes: 120  # 2時間
```

### アカウント設定
```python
# config.py
ACCOUNTS = {
    "心理テストラボ": {...},
    "闇夜の語り部": {...},
    "映画紹介": {...}
}
```

### API設定
```yaml
env:
  PEXELS_API_KEY: ${{ secrets.PEXELS_API_KEY }}
  PIXABAY_API_KEY: ${{ secrets.PIXABAY_API_KEY }}
  OLLAMA_MODEL: ${{ secrets.OLLAMA_MODEL }}
```

## 🚨 エラーハンドリング

### サービス起動失敗
```
Ollama → 自動起動を試行 → タイムアウトまで待機
VOICEVOX → Dockerコンテナを起動 → 接続確認
```

### 動画生成失敗
```
- エラーログを記録
- 一部のアカウントが失敗しても継続
- 成功したアカウントの動画は保存
```

### クリーンアップ
```
- 一時ファイル削除 (clip*.mp4, temp_*.mp4)
- 実行完了後は常に実行 (if: always())
```

## 📈 モニタリング

### 確認方法
1. **実行履歴**: Actions タブ
2. **ログ**: 各ステップの詳細ログ
3. **成果物**: Artifacts セクション
4. **統計**: Insights → Actions

### 通知設定（オプション）
```yaml
- name: Slack通知
  uses: 8398a7/action-slack@v3
  with:
    status: ${{ job.status }}
```

## 🔐 セキュリティ

### Secrets管理
- API キーは GitHub Secrets に保存
- ワークフロー内で環境変数として参照
- コード内にハードコードしない

### アクセス制御
- プライベートリポジトリ推奨
- セルフホストランナーは適切なファイアウォール設定
